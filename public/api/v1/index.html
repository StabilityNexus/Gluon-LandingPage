Gluon Protocol API v1

Version: 1.0.0

Machine-readable versioned API for the Gluon stablecoin protocol.

Endpoints

  • GET /api/info.json — Full protocol metadata (JSON)
  • GET /openapi.json — OpenAPI 3.0.1 specification
  • GET /llms.txt — LLMs.txt for AI agents
