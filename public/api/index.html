Gluon Protocol API

Version: 1.0.0

Machine-readable API for the Gluon stablecoin protocol. Returns protocol metadata, ecosystem instances, and repository links.

Endpoints

  • /api/info.json — Full protocol metadata (JSON)
  • /openapi.json — OpenAPI 3.0.1 specification
  • /llms.txt — LLMs.txt for AI agents
